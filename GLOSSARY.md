# Glossary

This vocabulary describes the shortener. The [glossary map](GLOSSARY-MAP.md) links terms to their implementation.

| Term | Meaning |
| --- | --- |
| Link | A record associating a code with a destination and lifecycle state. |
| ID | A database-generated positive integer used to manage a link. It is distinct from the public code. |
| Code | The case-sensitive public identifier for a link, generated by the application or supplied as an alias. |
| Alias | A code selected by the caller at creation. It is not stored as a separate field. |
| Destination | The HTTP or HTTPS URL to which an available link redirects. |
| Short URL | The configured public base URL combined with the code. It is returned to clients rather than stored. |
| Active | A flag controlled by management operations. An active link can still be expired or deleted. |
| Expired | A link with an expiration at or before the current time. An expired link cannot redirect. |
| Deleted | A soft-deleted link, hidden from management reads while its database row remains. Public resolution follows the [cache consistency bound](docs/architecture.md#redirect-cache). |
| Reserved code | A code held by any link, including a deleted link, and unavailable for a new link. Technical route names are also unavailable as aliases. |
| Pagination | A one-based page and page size over non-deleted links. Inactive and expired links remain visible. |
